## Application Description

The Community Learning Center Management System is a
Dart console application designed to manage learning
resources and participants.

It allows users to register participants, add learning
resources, borrow and return resources, search records,
and view system summaries.

## Features

1. Add Learning Resources
2. Register Participants
3. Borrow Learning Resources
4. Return Learning Resources
5. View All Records
6. Search Records
7. View System Summary
8. Input Validation and Error Handling
